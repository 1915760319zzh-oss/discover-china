# How to Deploy Your Website to Netlify

## Option 1: Drag & Drop (Easiest)

1. Open https://app.netlify.com/drop in your browser
2. Drag the folder `C:\Users\888\Desktop\china-travel-website` to the drop zone
3. Your site will be live in seconds with a URL like: https://random-name-123.netlify.app

## Option 2: Using the Zip File

1. Go to https://app.netlify.com/drop
2. Click "choose a file"
3. Select `C:\Users\888\Desktop\china-travel-website.zip`
4. Your site will be deployed automatically

## Option 3: GitHub + Netlify (Recommended for updates)

1. Create a GitHub account at https://github.com
2. Create a new repository
3. Upload your website files
4. Connect GitHub to Netlify
5. Every time you update the code, Netlify automatically redeploys

## After Deployment

- You'll get a free URL like: https://your-site-name.netlify.app
- You can add a custom domain later (e.g., www.discoverchina.com)
- Netlify provides free HTTPS/SSL
- Global CDN for fast loading worldwide

## Alternative: Vercel

1. Go to https://vercel.com
2. Sign up with GitHub
3. Import your repository
4. Deploy with one click

## Alternative: GitHub Pages (Free)

1. Create GitHub repository
2. Upload files to `main` branch
3. Go to Settings > Pages
4. Enable GitHub Pages
5. Your site will be at: https://username.github.io/repository-name

## Recommended: Netlify

**Why Netlify?**
- Free tier is generous
- Drag & drop deployment (no coding needed)
- Automatic HTTPS
- Global CDN (fast in USA, Europe, etc.)
- Custom domain support
- Form handling for forum
