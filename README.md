# Discover China - Tourism Website

## Overview
A comprehensive English-language tourism website for foreign visitors to China, featuring 15 carefully selected attractions, travel information, and a community forum.

## Features
- **15 Must-Visit Destinations** with detailed guides including:
  - Overview and description
  - Key highlights
  - Transportation options
  - Accommodation recommendations
  - Local food specialties
  - Travel tips and best seasons

- **Visa & Travel Information**
  - Visa-free entry policies (50 countries as of 2026)
  - Best times to visit
  - Essential apps (WeChat, Alipay, DiDi, Baidu Maps)
  - Emergency contacts

- **Travel Forum**
  - Community discussions
  - Experience sharing
  - Travel tips exchange

## Technology Stack
- HTML5
- CSS3 (responsive design)
- JavaScript (vanilla)
- No backend required (static site)

## Deployment Options
1. **Netlify** (recommended) - Free, fast CDN, automatic HTTPS
2. **Vercel** - Free, good performance
3. **GitHub Pages** - Free, easy setup
4. **AWS S3 + CloudFront** - Scalable, pay-per-use
